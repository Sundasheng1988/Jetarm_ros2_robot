# Read First

The canonical architecture documentation lives in:

- docs/architecture.md
- docs/mobile_robot_extension.md
- docs/topic_service_map.md
- docs/runtime_index.md

Do not infer or redesign system architecture without reading them.

If information is missing:

- Ask the user.
- Mark as TODO/VERIFY.
- Never assume deployment locations.
- Never assume ownership of packages.
